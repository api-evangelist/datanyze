# Datanyze

> Datanyze is a sales-intelligence and technographic data brand owned by ZoomInfo. It ships a free
> Chrome extension that surfaces business contact information — work email addresses, direct-dial
> and mobile numbers, and company firmographics — for prospects on LinkedIn profiles and company
> websites. Datanyze pioneered "technographics," the practice of tracking which web technologies a
> company runs in order to target B2B outreach. ZoomInfo acquired Datanyze in 2018.

## Status of the developer surface

Datanyze publishes **no public developer API**. As of 2026-08-13 there is no developer portal, no
API reference, no OpenAPI/AsyncAPI/GraphQL contract, no MCP server, no A2A agent card, no
`/.well-known/` discovery document, and no first-party SDK on any public package registry. The
public website is a frozen technographics content archive: its sitemap carries 32,286 URLs, all of
them `/market-share/*` pages, last modified 2021-04-21.

A live application backend answers at `https://api.datanyze.com` (Express/NestJS behind Cloudflare),
but it is the private backend for the Chrome extension, not a documented product: every probed path
returns `{"message":"Cannot GET /...","error":"Not Found","statusCode":404}`, and no specification
is served from it. It is recorded here for accuracy and is **not** an integration target.

Programmatic access to ZoomInfo data is a **ZoomInfo** product, sold and documented by ZoomInfo
under its own domain. It is not a Datanyze API and is not attributed to Datanyze in this profile.

## Products

- [Datanyze Chrome extension](https://www.datanyze.com/): contact lookup on LinkedIn and company sites
- [Technology market share](https://www.datanyze.com/market-share): technographic share-of-market pages by technology category
